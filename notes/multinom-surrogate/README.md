# Multinomial surrogate residuals

The implementation uses all `K + 1` utilities for an `mgcv::multinom(K)` GAM,
including category 0. Locations are `(0, eta_1, ..., eta_K)`, taken from the
fitted linear predictors, with their fitted offsets and random effects.
`mgcv` stores these predictors in `fitted.values` too; that field is not a
matrix of response probabilities. Returned residual matrices have columns
`"0"`, ..., `"K"` and one row per observation.

For utility `U_j = mu_j + G_j`, the independent errors have CDF
`F(g) = exp(-exp(-g))`. Residuals subtract the fitted location and Euler's
constant, `-digamma(1)`. Thus their reference has mean zero and variance
`pi^2 / 6` in every component. Both components remain in a binary fit. Their
difference has a logistic reference; differences sharing a reference utility
would be dependent.

## Conditional sampler

Write `A = log(sum(exp(mu)))` and `M = max(U)`. The joint density of the
maximum and winning label `y` is

```
f(M = m, Y = y) = exp(mu_y - m) exp(-exp(A - m))
               = exp(mu_y - A) f_Gumbel(A, 1)(m).
```

Consequently, the maximum is independent of the label and remains
`Gumbel(A, 1)` conditional on the observed category. Conditional on its value
`m`, each losing utility has CDF `F_j(u) / F_j(m)` for `u < m`. If `E_j` is an
independent standard exponential draw, its utility is

```
U_j = mu_j - log(exp(mu_j - m) + E_j).
```

The winning utility equals `m`. The code evaluates the sum inside the logarithm
using the two log terms, avoiding overflow and underflow. Equivalently,
`exp(-U_j)` are exponential arrival times: the minimum is independent of its
label, and the remaining times use the exponential memoryless property. This
requires a fixed amount of work for every observation, even when the observed
winner has extremely small fitted probability. It needs neither rejection nor
Gibbs iterations. Random numbers are assigned to complete rows in order, so
chunk size does not change an explicit seeded draw.

Mixing these conditional draws over outcomes generated by the same choice
model recovers the original joint utility distribution. Subtracting locations
and the error mean therefore recovers independent centred Gumbel components
under the known-parameter null. Conditional on a particular observed outcome,
the utilities have the required joint truncation; they are not sampled as
independent residual replicates.

The construction follows [Cheng, Wang and Zhang (2021)](https://pmc.ncbi.nlm.nih.gov/articles/PMC8018589/),
*Journal of Computational and Graphical Statistics*, 30(1), 67–77,
[doi:10.1080/10618600.2020.1775618](https://doi.org/10.1080/10618600.2020.1775618).
The [supplementary derivations](https://www.ebi.ac.uk/biostudies/files/S-EPMC8018589/NIHMS1618328-supplement-Supp_2.pdf)
were read from the BioStudies archive: Appendix A specifies conditional
truncation and a general Gibbs sampler, Appendix B gives the fitted-parameter
reference argument, and Appendix C derives the choice probabilities. The
maximum identity above supplies a direct sampler for the independent Gumbel
case. The existing ordinal construction remains unchanged.

## Diagnostic displays

One draw is shared across an appraisal's panels. QQ and worm plots use centred
Gumbel quantiles, with pointwise beta order-statistic bands calculated separately
for each category. The bands condition on fitted parameters and do not provide
simultaneous coverage across categories. Utilities are always separated, even
if grouped-family pooling is requested.

Residual-versus-fitted panels use the fitted probability of their own category.
This gives category 0 a useful varying horizontal axis despite its zero utility
location. Observed-versus-fitted panels use the corresponding zero/one category
indicator. Covariate plots also retain separate category panels. Captions have
not been expanded with methodological explanations.

Prepared diagnostics keep a wide residual matrix and observation rows. Scalable
displays process each component before combining bounded QQ, histogram or grid
summaries; they do not build a full long table of repeated observations for every
panel. Automatic dispatch counts observations. QQ sorting retains row identities
until aggregation; binned summaries do not carry averaged observation IDs.

Supported nominal fits are `mgcv::gam` models with `multinom()`. The scalar
ordered-correlation helpers give an explicit error for nominal utility matrices;
individual columns can be inspected separately. Ordinary/scalable residual,
QQ, worm, histogram, predictor and appraisal paths are supported.
