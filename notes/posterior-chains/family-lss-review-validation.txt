Review fixes:
- Use the existing missing-safe response wrapper for LSS posterior draws.
  Native generators that ignore weights previously produced responses at
  missing explicit weights. Such rows now return NA, matching fixed-parameter
  simulation, and usable rows retain the same seeded responses as a subset.
  Added 28 assertions across all seven LSS families, including all-missing weights.
- Clarify that MH holds parameters outside the coefficient vector fixed;
  LSS scale and shape coefficients are sampled jointly with location.
- Describe coefficient uncertainty precisely in the reference index, and link
  its sampling section directly to chain diagnostics and the migration guide.
Amended the existing unreleased feature entry; no capability was added under
User visible changes. No unresolved regressions were found in the reviewed work.
